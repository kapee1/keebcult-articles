# Keebcult Wiki - База знаний о механических клавиатурах

## O сайте

Это репозиторий GitHub Pages для [Keebcult](https://keebcult.notion.site) — вики, посвященной механическим клавиатурам. Здесь собрана информация о различных аспектах механических клавиатур, от терминологии до практических гайдов по выбору, сборке и обслуживанию.

Сайт использует [Jekyll](https://jekyllrb.com/) с темой [Just the Docs](https://just-the-docs.github.io/just-the-docs/).

## Локальное запуска

### Требования

- Ruby 2.7+
- Jekyll 3.9+
- Bundler

### Установка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/keebcult-articles.git
cd keebcult-articles

# Установите зависимости
bundle install

# Запустите локальный сервер
bundle exec jekyll serve

# Сайт будет доступен на http://localhost:4000/keebcult-articles/
```

## Структура проекта

keebcult-articles/
