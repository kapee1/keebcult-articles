# Инструменты для сборки клавиатуры

## Необходимый минимум

Для сборки кастомной клавиатуры вам понадобятся:

- **Пинцет** — для установки свичей и работы с мелкими деталями
- **Паяльник** (для некоторых плат) — необходимо только для припайки свичей на плату без горячей замены
- **Кабель USB** — для подключения клавиатуры

## Инструменты для смазки свичей

Если вы планируете смазывать свичи самостоятельно:

- **Смазка** (обычно силиконовая или синтетическая)
- **Малая кисточка** — для нанесения смазки
- **Отвёртка** — для открытия переключателей

## Дополнительные материалы

- Изолента или скотч
- Салфетки для чистки
- Защитные очки (при работе с паяльником)
