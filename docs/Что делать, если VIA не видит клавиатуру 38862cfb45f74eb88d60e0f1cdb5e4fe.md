# Что делать, если VIA не видит клавиатуру

Owner: keebcult

Если клавиатура поддерживает VIA/QMK, то ее можно настроить через приложение или в браузере, который поддерживает usb HID.

Видео:

[via_json.mp4](%D0%A7%D1%82%D0%BE%20%D0%B4%D0%B5%D0%BB%D0%B0%D1%82%D1%8C,%20%D0%B5%D1%81%D0%BB%D0%B8%20VIA%20%D0%BD%D0%B5%20%D0%B2%D0%B8%D0%B4%D0%B8%D1%82%20%D0%BA%D0%BB%D0%B0%D0%B2%D0%B8%D0%B0%D1%82%D1%83%D1%80%D1%83/via_json.mp4)

Текстовое описание:

1. Подключить клавиатуру по проводу. Конфигурирование по bluetooth недоступно, а по радио донглу достоверных подтверждений нет.
2. Открыть сайт [https://usevia.app/](https://usevia.app/)
3. Подключиться к клавиатуре нажав на кнопку **Authorize device**.
*Если у клавиатуры полная поддержка, то на этом процесс заканчивается и появляется возможность управлять настройками клавиатуры, но иногда требуется использовать специальный json файл для конкретной модели клавиатуры.*
4.  Скачать на устройство json файл.
*Например для клавиатур Neo/QK есть [отдельная страница](https://www.qwertykeys.com/pages/fw) на сайте производителя.*
5. Перейти на вкладку **Settings** и передвинуть ползунок **Show Design Tab** во включенное состояние
6. Перейти на вкладку **Design** и выполнить одно из двух действий
    1. Или перетащить файл в зону **drag&drop**
    2. Или нажать на кнопку **Load** в строке **Load Draft Defenition** и выбрать нужный файл.
    *Опционально, при возникновении ошибок загрузки, можно попробовать включить или выключить опцию **Use V2 definitions***
7. Если все прошло успешно, сайт снова откроет диалог подключения клавиатуры, а в строке **Draft Definitions** должна появиться добавленная клавиатура. Иногда требуется обновить страницу для корректной работы.
