# Какие линейные свичи купить?

Owner: keebcult

Хорошие производители: Tecsee, Haimu, Gateron

Посмотреть кто производит тот или иной свич можно на сайте [switches.mx](https://switches.mx/switches/) (перейти на страничку свича, там будет поле Manufacturer - производитель)
