# Быстрая справка по механическим клавиатурам

## Термины в одной строке

| Термин | Значение |
|--------|----------|
| **Свич** | Механический переключатель |
| **Линейный** | Гладкий без обратной связи |
| **Тактильный** | С "тычком" в середине |
| **Кликающий** | С характерным щелчком |
| **Лубинг** | Смазка свичей |
| **Стаб** | Стабилизатор для длинных клавиш |
| **Hotswap** | Горячая замена свичей без пайки |
| **Кейкап** | Колпачок на клавишу |
| **PCB** | Электронная плата |
| **Case** | Корпус клавиатуры |

## Рекомендации для новичков

### Свичи
✅ Gateron Yellow — мягкие, популярные  
✅ Huano Blue — дешевые, хорошие  
✅ Cherry MX Red — классика  
❌ Слишком дешевые копии — могут быть хрупкими

### Стабилизаторы
✅ Durock — хорошее качество  
✅ Gateron — надежные  
✅ Staebies — популярны в комьюнити  
❌ Дешевые копии Cherry — люфты и проблемы

### Кейкапы
✅ Cherry профиль — стандарт  
✅ PBT материал — прочный  
✅ Средняя цена — лучшее соотношение  
❌ Очень дешевые — хрупкий пластик

## Модификации (опционально)

### Небольшые (90% результата)
- 🔧 Смазка свичей (лубинг)
- 🔨 Наклейка нижней пластины
- 🎀 Смазка стабилизаторов

### Продвинутые (для экспериментов)
- 🔄 Замена пружин
- 📌 Добавление пленки (filming)
- 🎨 Обрезание ножек стабилизаторов (clipping)

## Частые ошибки новичков

❌ **Слишком много смазки** → Feel становится "масляным"  
❌ **Неправильная установка стабилизаторов** → Люфты и странные звуки  
❌ **Дешевые копии свичей** → Ломаются быстро  
❌ **Игнорирование прокладок** → Полный металлический звук  
❌ **Спешка при сборке** → Ошибки и разочарование

## Советы для улучшения

1. **Слушайте полученный звук** — он подскажет, всё ли в порядке
2. **Экспериментируйте** — каждая клавиатура уникальна
3. **Присоединяйтесь к комьюнити** — там много опыта
4. **Начните с простого** — базовое качество важнее премиума
5. **Получайте удовольствие** — это хобби, а не работа!
