# Полезные советы

Owner: keebcult

Чтобы жало прослужило дольше - нужно выключать паяльник в перерывах. У продвинутых паяльных станций (типа Hakko FX951) есть функция autosleep именно для этого.

Если же у паяльника такой функции нет - можно использовать переноску с кнопкой.

![Untitled](%D0%9F%D0%BE%D0%BB%D0%B5%D0%B7%D0%BD%D1%8B%D0%B5%20%D1%81%D0%BE%D0%B2%D0%B5%D1%82%D1%8B/Untitled.png)

![Untitled](%D0%9F%D0%BE%D0%BB%D0%B5%D0%B7%D0%BD%D1%8B%D0%B5%20%D1%81%D0%BE%D0%B2%D0%B5%D1%82%D1%8B/Untitled%201.png)

При пайке нужно не просто расплавить припой, а нагреть две поверхности и расплавить припой на них. При этом припой должен быть свежим, т.к. в нем есть флюс.

![Untitled](%D0%9F%D0%BE%D0%BB%D0%B5%D0%B7%D0%BD%D1%8B%D0%B5%20%D1%81%D0%BE%D0%B2%D0%B5%D1%82%D1%8B/Untitled%203.png)

![Untitled](%D0%9F%D0%BE%D0%BB%D0%B5%D0%B7%D0%BD%D1%8B%D0%B5%20%D1%81%D0%BE%D0%B2%D0%B5%D1%82%D1%8B/Untitled%204.png)

Хорошая температура для пайки: 300-325 градусов

Если припой слишком толстый - будет много остатков, которые повиснут на паяльнике.

![Untitled](%D0%9F%D0%BE%D0%BB%D0%B5%D0%B7%D0%BD%D1%8B%D0%B5%20%D1%81%D0%BE%D0%B2%D0%B5%D1%82%D1%8B/Untitled%2010.png)

Если припой будет слишком тонким - его нужно будет долго наносить, соответственно, оплетка начнет плавиться.
