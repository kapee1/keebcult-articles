# Я хочу собрать кастомную клавиатуру, что мне для этого нужно?

Для сборки кастомной клавиатуры вам потребуется:

1. **Кит** (дом, база, основа) - включает корпус, PCB, пластину, стабилизаторы
2. **Свичи** - механические переключатели
3. **Кейкапы** - колпачки на клавиши
4. **Стабилизаторы** - в большинстве случаев (часто идут в кит)
5. **Инструменты** - для сборки и модификации

Начните с выбора комплекта (кита), затем подберите свичи, стабилизаторы если нужны, кейкапы и приступайте к сборке!
