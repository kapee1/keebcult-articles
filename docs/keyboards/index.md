# Клавиатуры

В этом разделе вы найдете полное руководство по выбору и сборке кастомных механических клавиатур.

## Основные статьи

- **Что мне нужно для сборки своей первой кастомной клавиатуры?** - базовое руководство для новичков
- **Гайд по пребилдам в бюджете от 5 до 15 тысяч рублей** - рекомендации готовых клавиатур на любой бюджет
- **Типы крепления в клавиатурах** - полный разбор систем крепления (gasket, tray-mount, top-mount и т.д.)
