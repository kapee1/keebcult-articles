# Линейные свичи: полное руководство

Линейные свичи — лучший выбор для новичков. Они обеспечивают гладкое движение без какой-либо тактильной обратной связи.

## Почему линейные свичи для новичков?

1. **Простота** — прямолинейное движение без сюрпризов
2. **Тихость** — меньше шума при печати
3. **Цена** — обычно дешевле других типов
4. **Надежность** — меньше движущихся частей

## Характеристики линейных свичей

### Усилие активации
- **45g** — мягкие, подходят для долгой печати
- **50g** — стандарт, универсальный выбор
- **60g** — жестче, требуют сильного нажатия

### Ход
- **4mm** — стандартный ход
- **3.5mm** — укороченные (gaming feel)

## Популярные линейные свичи

### Gateron Yellow (Yellowstone)
- **Вес:** 45-50g
- **Ход:** 4mm
- **Цена:** экономичные
- **Качество:** отличное для бюджета
- ✅ **Рекомендуется новичкам**

### Huano Blue/Black
- Очень дешевые
- Хорошее качество за цену
- Более жесткие пружины

### Kalih Box Red/Black
- Качественная конструкция
- Немного дороже, но очень надежные
- Популярны среди опытных пользователей

### Cherry MX Red
- **Легендарные свичи**
- Дорогие, но очень надежные
- Стандарт механических клавиатур с 1985 года

## Long-Pole vs обычные свичи

**Long-pole свичи** имеют более длинный толкатель, который контактирует со стебельком дольше.

- Дают более мягкое ощущение
- Требуют более тщательной установки
- Обычно дороже

## Советы для выбора

1. Начните с **Gateron Yellow** или **Huano** — хороший баланс цены и качества
2. Попробуйте разные веса перед покупкой полного набора (если есть возможность)
3. Берите хотя бы 108 свичей для полной клавиатуры (+ несколько запасных)
4. Смажьте свичи для лучшего feel

## Смазка линейных свичей

Смазанные свичи:
- Звучат лучше (более мягкий/глубокий звук)
- Чувствуют себя лучше (плавнее)
- Служат дольше

### Как смазать свич:
1. Откройте корпус свича
2. Нанесите тонкий слой смазки на направляющие
3. Смажьте пружину (равномерно)
4. Соберите обратно

## Следующий шаг

Когда вы будете готовы экспериментировать, попробуйте **тактильные свичи** — они обеспечивают легкую обратную связь при нажатии.
