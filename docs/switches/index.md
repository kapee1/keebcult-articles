# Свичи (Переключатели)

Свичи — это сердце механической клавиатуры. Правильный выбор переключателей определяет ваше удобство и опыт использования.

## Основные типы свичей

### Линейные (Linear)
Обеспечивают гладкое движение без тактильной обратной связи. Лучше всего для быстрого набора текста и игр.

### Тактильные (Tactile)
Обеспечивают легкое "щелчком" в середине хода без звука. Идеальны для программистов и писателей.

### Кликающие (Clicky)
Издают характерный щелчок при каждом нажатии. Самые шумные, но самые удовлетворяющие.
