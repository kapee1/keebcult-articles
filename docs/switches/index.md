# Свичи (Переключатели)

Свичи — это сердце механической клавиатуры. Правильный выбор переключателей определяет ваше удобство и опыт использования.

## Основные типы свичей

### Линейные (Linear)
Новичкам стоит начать свой путь с линейных свичей. Они обеспечивают гладкое движение без тактильной обратной связи.

### Тактильные (Tactile)
Обеспечивают легкое "щелчком" в середине хода без звука.

### Кликающие (Clicky)
Издают характерный щелчок при каждом нажатии.
