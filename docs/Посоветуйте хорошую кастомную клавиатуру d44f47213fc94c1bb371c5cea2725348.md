# Посоветуйте хорошую кастомную клавиатуру

Owner: keebcult

Ниже представлены варианты, которые более-менее реально найти в продаже на вторичном рынке ([мехмаркет](https://www.reddit.com/r/mechmarket), [ру_мехмаркет](https://www.reddit.com/r/ru_mechmarket/), [авито](http://avito.ru), фиш ([iOS](https://apps.apple.com/app/id510909506), [Android](https://play.google.com/store/apps/details?id=com.taobao.idlefish))).

Если вы хотите купить новую клавиатуру, то необходимо мониторить релизы дизайн-студий. Это можно делать в нашем телеграм-канале (где есть [раздел с новостями](https://t.me/keebcult/2348)), либо в дискорд-серверах студий, например: [qwertykeys](https://discord.com/invite/tJvRQbDB?utm_source=Discord%20Widget&utm_medium=Connect), [geonworks](https://discord.gg/geon).

Для начала лучше выбирать клавиатуры с hotswap pcb (возможность установки и замены свичей без пайки) - с ними гораздо легче исправить стабилизаторы или поменять свичи.
