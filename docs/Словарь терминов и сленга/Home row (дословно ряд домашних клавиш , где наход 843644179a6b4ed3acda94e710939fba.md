# Home row (дословно "ряд домашних клавиш", где находятся буквы F и J)

Owner: keebcult

Это концепция в мире печати, особенно касающаяся машинного метода печати на клавиатуре. Home row представляет собой средний ряд клавиш на клавиатуре, на который устанавливают пальцы во время начала печати. Этот ряд находится по центру клавиатуры и включает следующие клавиши:

Для клавиш английского языка:

Левая рука: A, S, D, F.

Правая рука: J, K, L, ;.
