# Словарь терминов и сленга механических клавиатур

## Основные термины

### Свичи и компоненты

**Свич** — механический переключатель (переключатель)
- **Liner (Linear)** — линейный свич без тактильной обратной связи
- **Tactile** — тактильный свич с "тычком" в середине хода
- **Clicky** — кликающий свич с характерным щелчком
- **Long-pole** — свич с удлиненным толкателем
- **Holy Panda** — гибридный тактильный свич из компонентов разных свичей

**Стабилизатор (Stab)** — механизм для длинных клавиш
- **PCB mount** — крепление к плате
- **Plate mount** — крепление к пластине

**Кейкап** — колпачок на клавишу
- **Profile** — форма кейкапа (Cherry, OEM, SA и т.д.)
- **Keyset** — полный набор кейкапов

### Характеристики

**Вес** — усилие активации (45g, 50g, 60g)
**Ход** — расстояние нажатия (4mm, 3.5mm)
**Актуализация** — точка срабатывания свича

## Типы крепления и монтажа

**Tray Mount** — крепление PCB к корпусу через несколько точек опоры
**Gasket Mount** — эластичное крепление PCB через полоски
**Top Mount** — крепление пластины сверху корпуса
**Hotswap** — возможность быстрой смены свичей без пайки

## Материалы и конструкция

**PCB** — печатная плата с электроникой
**Plate (пластина)** — опора для свичей и стабилизаторов
**Case (корпус)** — внешний защитный слой
**Stabilizer (стаб)** — механизм стабилизации последний клавиш
**Foam (пена)** — прокладка между компонентами для демпфирования

## Модификации и кастомизация

**Lubing** — смазка свичей
**Clipping** — обрезание ножек стабилизатора
**Film** — специальная прокладка на свич
**Case foam** — пена внутрь корпуса
**PCB foam** — пена под PCB
**Plate foam** — пена под пластину

## Звук и feel

**Thocky** — глубокий, приятный звук "тук"
**Clacky** — звонкий звук "клак"
**Poppy** — звучный, отчетливый звук
**Scratchy** — царапающий звук (обычно плохой)
**Ping** — высокочастотный посторонний звук
**Rattle** — дребезжание
**Tactility** — ощутимая обратная связь

## Сообщество и культура

**Keeb** — сокращение от keyboard
**Keebporn** — красивые фотографии клавиатур
**Zealously** — по имени производителя ZealPC
**WKL** (Winkey-less) — клавиатура без кнопки Windows
**60%/65%/75%** — процент размера полной клавиатуры
**TKL** — Tenkeyless, без цифрового блока
**Full-size** — полный размер (104 клавиши)

## Бренды

**GMK** — премиальные ABS кейкапы
**PBT Fans / EPBT** — качественные PBT кейкапы
**Gateron** — популярные свичи среднего ценового диапазона
**Cherry MX** — легендарные механические свичи
**Durock** — качественные стабилизаторы
**Huanuo / Huano** — бюджетные китайские свичи

## Аббревиатуры

- **PCB** — Printed Circuit Board (печатная плата)
- **PBT** — Polybutylene Terephthalate (материал)
- **ABS** — Acrylonitrile Butadiene Styrene (материал)
- **MX** — Cherry MX (стандарт)
- **Choc** — Kailh Choc (альтернативный стандарт)
- **WKL** — Winkey-less (без кнопки Windows)
- **TKL** — TenKeyless (без цифрового блока)
- **ANSI** — США раскладка (в отличие от ISO европейской)
