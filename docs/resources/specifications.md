# Спецификации MX и Choc

## MX стандарт (Cherry MX)

### Габариты хаузинга

| Параметр | Значение |
|----------|----------|
| Ширина | 14.0 mm |
| Длина | 14.0 mm |
| Высота | 11.6 mm (только хаузинг) |
| Высота стема над хаузингом | 2.7 mm |

### Стем

| Параметр | Значение |
|----------|----------|
| Тип | Plus (+) форма |
| Ширина | 4.0 mm |
| Глубина | 4.0 mm |
| Высота | зависит от типа свича |

### Контакты

| Параметр | Значение |
|----------|----------|
| Расстояние между контактами | 19.05 mm |
| Тип контактов | Плоские лепестки |
| Материал | Латунь или пружинная сталь |

### Пружина

| Параметр | Значение |
|----------|----------|
| Тип | Спиральная, однонаправленная |
| Усилие | 45-80 cN (в зависимости от типа) |
| Материал | Пружинная сталь |

## Choc стандарт (Kailh Choc)

### Габариты хаузинга

| Параметр | Значение |
|----------|----------|
| Ширина | 18.0 mm |
| Длина | 16.0 mm |
| Высота | 7.1 mm (только хаузинг) |
| Высота стема над хаузингом | 2.0 mm |

### Стем

| Параметр | Значение |
|----------|----------|
| Тип | Сферический или U-образный |
| Ширина | ~7.0 mm |
| Глубина | ~8.0 mm |
| Высота | зависит от типа свича |

### Контакты

| Параметр | Значение |
|----------|----------|
| Расстояние между контактами | varying |
| Тип контактов | Пружинные ножки |
| Материал | Латунь или пружинная сталь |

### Пружина

| Параметр | Значение |
|----------|----------|
| Тип | Спираль или плоская пружина |
| Усилие | 40-70 cN |
| Материал | Пружинная сталь |

## Сравнение MX vs Choc

| Параметр | MX | Choc |
|----------|----|----|
| Высота | Высокий профиль | Низкий профиль |
| Размер хаузинга | Больше | Меньше |
| Доступность | Массовое производство | Растущий стандарт |
| Дешевизна | Более доступен | Дороже |
| Кейкапы | Много опций | Мало опций |
| Свичи | Тонна вариантов | Развивающийся рынок |

## Совместимость

**MX свичи НЕ совместимы с Choc** - разные стемы и контакты.

Хотя существуют различные переходные платы и адаптеры, они редко используются на практике.

## Стандартные типы свичей

### MX типы

- Linear (e.g., Cherry MX Red)
- Tactile (e.g., Cherry MX Brown)
- Clicky (e.g., Cherry MX Blue)

### Choc типы

- Choc Red (Linear)
- Choc Brown (Tactile weaker)
- Choc White (Clicky)

## Горячая замена (Hotswap)

### MX типы контактов

- **3-pin** - стандартный для большинства ПСБ (PCB)
- **5-pin** - дополнительное крепление для того, чтобы свич не шатался

### Choc типы контактов

- **Choc socket** - специальные сокеты для низкопрофильных свичей
- Не совместима с MX

---

**Примечание:** Спецификации варьируются в зависимости от производителя. Используйте это как общее руководство.
