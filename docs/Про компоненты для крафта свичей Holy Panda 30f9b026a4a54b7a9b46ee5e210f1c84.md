# Про компоненты для крафта свичей Holy Panda

Owner: keebcult

Автор: Кирилл Шкурецкий

👍 Есть ог панды с лого инвира в классической расцветке, дата выхода 2017 год - их ты не найдешь

👍 Есть бсан джизас с лого бсан, выпуск как правило до 2019 года - их ты тоже не найдешь

👍 Есть йок 3 пин в четырех цветах (треш, минт, ред, полар) - лучший вариант

👍 Есть йок 5 пин в тех же цветах. Лучше по качеству изготовления (не ломаются), но все равно проебаны по всем измерениям и доп. пины ничего не дают, свитчи не держатся в пцб - также заебатый вариант

🤮 Есть йок 5 пин с прозрачным хаузингом - полная дрисня по звуку

🤮 Есть те же прозрачные йоки, но под брендом бсан - полная дрисня по звуку

🤡 Есть пом панды под брендами инвир, йок и бсан - не оригинальные молды

🤡 Есть инвир панды с дропа, а также холи панды с дропа - не оригинальные молды, посмешище холи пандного мира

👍 - можно брать, оригинальные молды
🤮 - нельзя брать, оригинальные молды, но плохие материалы
🤡 - нельзя брать, неоригинальные молды
